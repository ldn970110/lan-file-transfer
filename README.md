# 📁 區域網路檔案傳輸工具

在兩台 Windows 電腦之間透過區域網路（LAN）快速傳輸檔案的桌面應用程式。

## ✨ 功能特色

- 🔍 **自動發現裝置** — 同一區域網路內的裝置自動出現在列表中
- 📄 **單檔/多檔傳輸** — 選擇或直接拖放一個或多個檔案，可分批加入、個別移除
- 📂 **資料夾傳輸** — 將整個資料夾（含子目錄）完整傳送
- 📊 **即時進度顯示** — 進度條、傳輸速度、預估剩餘時間
- 🔄 **斷點續傳** — 傳輸中斷後可從上次中斷的位置繼續
- 🔒 **SHA-256 驗證** — 傳輸完成後自動驗證檔案完整性
- 🌙 **深色主題** — 深灰底色的深色介面

## 📦 安裝

### 需求
- Python 3.10 或更新版本
- Windows 10/11

### 安裝步驟

```bash
# 1. 進入專案目錄
cd 檔案傳輸

# 2. 建立虛擬環境
python -m venv .venv

# 3. 啟動虛擬環境
.venv\Scripts\activate

# 4. 安裝依賴
pip install -r requirements.txt

# 5. 執行程式
python main.py
```

## 🚀 使用方式

### 傳送檔案
1. 在兩台電腦上分別啟動程式
2. 等待左側「線上裝置」列表出現對方的電腦
3. 點選目標裝置
4. 把檔案或資料夾拖放到視窗中，或點擊「選擇檔案」/「選擇資料夾」
5. 點擊「🚀 傳送」

### 接收檔案
1. 當對方傳送檔案時，「傳輸記錄」最上方會出現請求卡片，點「接受」或「拒絕」（約 60 秒未回應自動拒絕）
2. 確認後檔案會自動儲存到指定目錄（預設為「下載」資料夾）
3. 可在介面底部變更或開啟儲存位置；接收完成後可點「開啟資料夾」

### 斷點續傳
- 如果傳輸中途中斷（例如網路斷線），重新傳送同一檔案時
- 程式會自動偵測已接收的部分，從斷點繼續傳輸

## ⚙️ 技術細節

| 項目 | 說明 |
|------|------|
| 裝置發現 | UDP 廣播（埠 50800） |
| 檔案傳輸 | TCP（埠 50801） |
| 分塊大小 | 1 MB |
| 完整性驗證 | SHA-256 |
| GUI 框架 | CustomTkinter |

## 🔥 防火牆設定

首次執行時，Windows 防火牆可能會詢問是否允許網路存取。
請選擇「允許存取」，否則裝置發現和檔案傳輸將無法正常運作。

需要開放的埠號：
- **UDP 50800** — 裝置發現
- **TCP 50801** — 檔案傳輸
